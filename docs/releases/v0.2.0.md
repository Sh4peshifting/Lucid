## Lucid · 清醒梦

Panel Awake 正式更名为 Lucid，意为“清醒梦”：让屏幕休息，让系统保持清醒。

- 应用、守护服务、状态解析和测试全部迁移为 Kotlin；界面采用 Jetpack Compose + Material Design 3。
- 全新首页：并列的实际状态卡片、两个独立守护开关、连接状态和可展开的使用说明。
- 支持系统浅色/深色模式与 Android 12+ 动态配色；更新月亮图标。
- 保留 Shizuku 独立守护、设置恢复与错误反馈。
- 沿用原来的包名和签名，可直接覆盖升级 v0.1.0 并保留开关设置，无需卸载旧版。

需要 Android 12+ 与已启动的 Shizuku 13+。连接并授权 Lucid 后开启“保持清醒”和“让屏幕休息”。手机重启或 Shizuku 停止后仍需重新连接。

云端执行 Kotlin 策略测试、Compose UI 测试、Android lint 和模拟器实际面板 OFF/Awake/ON 验证。真实 RustDesk 长期稳定性仍取决于系统与后台权限，本版本仍为实验性预发布。
